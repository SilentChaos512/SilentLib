# Credits

## Mixbox

Silent Lib uses Mixbox by scrtwpns for blending colors. Mixbox is packaged into the Silent Lib JAR file without
modifications other than being shadowed into another namespace to prevent mod conflicts. More information can be found
on the [Mixbox website](https://scrtwpns.com/mixbox/) and [GitHub](https://github.com/scrtwpns/mixbox).
